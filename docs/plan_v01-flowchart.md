## ① 요청 작성 · 요청자

텍스트 교정과 제출 검증은 서로 다른 흐름이다.

- **텍스트 교정**은 선택 기능이다. 첨부파일이 있는 자유입력형에서는 교정을 실행할 수 없다.
- **제출 검증**은 모든 요청에 항상 적용한다. 첨부파일이 있는 자유입력형도 공통 필수값과 첨부 조건을 검증한다. 교정만 제외된다.

```mermaid
flowchart TD
  a1(["작성 중"]) --> a2["공통 정보 입력 [요청자]<br/>제목·유형·희망 납기·목적·대상 고객·배경<br/>캠페인은 선택"]
  a2 --> a3["콘텐츠 작성 [요청자]<br/>유형별 입력·변수 검색 삽입·첨부·XLSX 대량 등록"]
  a3 --> a4["자동·수동 저장 [시스템]"]
  a4 --> c0

  subgraph C["텍스트 교정 — 선택 기능, 제출 조건 아님"]
    direction TB
    c0{"자유입력형에<br/>첨부파일이 있는가?"}
    c0 -- 예 --> c1["교정 제외 [시스템]<br/>교정 버튼·결과 영역 비활성<br/>전체 검사 대상에서 제외"]
    c0 -- 아니오 --> c2{"교정 실행? [요청자]"}
    c2 -- 실행 --> c3["유효 데이터셋으로 검사 [시스템]<br/>결과 카드 선택 → 문자열 위치 이동"]
    c3 --> c4["필요 시 문안 수정 [요청자]<br/>수정 후 기존 결과는 '최신 내용과 불일치'"]
    c1 -. "첨부를 모두 삭제하면 교정 다시 활성화" .-> c2
  end

  c1 --> v0
  c2 -- 미실행 --> v0
  c4 --> v0

  subgraph V["제출 검증 — 필수, 첨부 유무와 관계없이 항상 수행"]
    direction TB
    v0["검수 요청 [요청자]"] --> v1["공통 필수값 확인 [시스템]<br/>제목·유형(활성)·희망 납기·목적·대상 고객·배경"]
    v1 --> v2["유형별 필수값·연결값 확인 [시스템]<br/>알림톡: 승인 템플릿·본문·버튼명·버튼 링크<br/>문자: 발신자·본문 / RCS: 카드 본문·이미지 설명<br/>자유입력형: 텍스트 또는 첨부파일 1개 이상"]
    v2 --> v3["첨부 조건 확인 [시스템] — 첨부가 있을 때<br/>파일별 전체 분량·실제 검수 범위<br/>업로드·파일 검사 완료, 위험·실패 파일 없음"]
    v3 --> v4{"누락·오류가 있는가?"}
  end

  v4 -- 있음 --> v5["누락 항목 안내 [시스템]<br/>교정 결과가 없어도 제출 차단 사유가 아님"]
  v5 --> a3
  v4 -- 없음 --> v6["서버 저장 [시스템]"]
  v6 --> b0(["배정 대기"])
  b0 --> b1{"배정 전 취소? [요청자]"}
  b1 -- 예 --> b2["작성 중으로 복귀<br/>취소 이력 기록 · 검수 차수 유지"]
  b2 --> a1
  b1 -- 아니오 --> b3["② 배정으로"]
```

### 제출 검증 기준 — 자유입력형

| 검증 항목 | 첨부 없음 | 첨부 있음 |
|---|---|---|
| 공통 필수값 (제목·유형·희망 납기·목적·대상 고객·배경) | 검증 | 검증 |
| 텍스트 또는 첨부파일 1개 이상 | 검증 | 검증 |
| 파일별 전체 분량·실제 검수 범위 | 해당 없음 | 검증 |
| 업로드·파일 검사 완료, 위험·실패 파일 없음 | 해당 없음 | 검증 |
| 텍스트 교정 실행 | 선택 (제출 조건 아님) | 사용 불가 (교정 제외) |

## ③ 검수 · 배정 검수자

검수 작업과 검수 완료 처리는 담당자가 다르다.

- **검수 작업**은 배정된 검수자 전원이 한다.
- **요청 단위 검수 완료**와 **회수 승인·거절**은 주담당 검수자만 한다.
- **검수자·주담당 변경**은 대표 검수자가 `검수 중` 상태에서만 한다.

```mermaid

  r0(["검수 중"])

  subgraph W["검수 작업 — 배정 검수자 전원"]
    direction TB
    w1["문안 편집 [배정 검수자 전원]<br/>문안별 편집 잠금 · 저장 버전 비교"]
    w2["파일 수정본 등록 [배정 검수자 전원]<br/>기존 파일을 덮어쓰지 않고 새 버전"]
    w3["검수 의견 · 텍스트 교정 [배정 검수자 전원]"]
    w4["확인 요청 [배정 검수자 전원]<br/>질문·대상 콘텐츠 기록"]
  end

  r0 --> w1
  r0 --> w2
  r0 --> w3
  r0 --> w4

  w4 --> q0(["확인 요청<br/>요청 전체 검수 일시 중단"])
  q0 --> q1["답변 [요청자]"]
  q1 --> q2{"답변하며 문안을 수정했는가?"}
  q2 -- 아니오 --> q3["검수 중 복귀 · 차수 유지"]
  q2 -- 예 --> q4["검수 중 복귀 · 차수 +1"]
  q3 --> r0
  q4 --> r0

  subgraph P["주담당 검수자만"]
    direction TB
    p1["공동 검수 결과 · 최종 대상 버전 확인 [주담당만]"]

  k0 --> k1
  k1 -- 승인 --> k2["작성 중 복귀 · 활성 배정 해제<br/>재요청 시 차수 +1"]
  k1 -- 거절 --> r0

  subgraph X["검수자·주담당 변경 — 대표 검수자, 검수 중에서만"]

    x3 --> x4["변경 사유 · 인수인계 내용 입력 (필수) [대표 검수자]"]
    x4 --> x5["업무 이력 기록 [시스템]<br/>변경 전·후 검수자와 주담당, 사유, 인수인계 내용<br/>기존 검수 의견·수정 이력은 그대로 보존"]
    x5 --> x7["해제된 검수자의 편집 잠금 해제 [시스템]<br/>해제 사실도 이력에 기록"]
    x7 --> x6["알림 [시스템]<br/>요청자 · 추가·해제된 검수자 · 변경 전후 주담당"]

  r0 --> x0
  x6 --> r0
```

### 검수 단계 행동별 담당자

| 행동 | 처리 담당자 | 가능한 요청 상태 |
|---|---|---|
| 문안 편집 · 파일 수정본 등록 · 검수 의견 · 텍스트 교정 | 배정 검수자 전원 | 검수 중 |
| 확인 요청 | 배정 검수자 전원 | 검수 중 |
| 회수 승인 · 거절 | 주담당 검수자만 | 검수 중 (회수 요청됨) |
| 요청 단위 검수 완료 | 주담당 검수자만 | 검수 중 |
| 검수자 · 주담당 변경 | 대표 검수자 | 검수 중 |
| 편집 잠금 강제 해제 | 대표 검수자 · 고객사 관리자 | 검수 중 |

### 검수자 · 주담당 변경 가능 상태

| 요청 상태 | 변경 | 비고 |
|---|---|---|
| 배정 대기 | 최초 배정 | 변경이 아닌 최초 배정 |
| 검수 중 | 가능 | 변경 사유 · 인수인계 필수, 기존 기록 보존 |
| 확인 요청 | 불가 | 답변 후 검수 중으로 돌아오면 변경 가능 |
| 승인 대기 | 불가 | 콘텐츠 버전 · 검수자 · 주담당 고정 |
| 검수 완료 · 승인 완료 | 불가 | 최종 완료 |

## 검수 차수 규칙

| 구분 | 검수 차수 |
|---|---|
| 확인 요청 / 설명만 포함한 확인 응답 | 유지 |
| 검수자의 문안 · 파일 수정 | 유지 |
| 배정 전 취소 후 재요청 | 유지 |
| 확인 응답 중 요청자의 문안 수정 | +1 |
| 회수 승인 후 재요청 | +1 |
| 승인자의 수정 요청 | +1 |

콘텐츠 버전 증가와 검수 차수 증가는 서로 다른 개념이다.
